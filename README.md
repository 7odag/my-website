# My Website

مرحباً بك في مشروع الموقع الشخصي لبيع الهوديز!

## الوصف
هذا الموقع يهدف إلى بيع الهوديز بأسعار معقولة مع تصميمات رائعة.

## كيفية التشغيل
- لتحميل الملفات، قم بتحميلها من هذا المستودع.
- افتح ملف `index.html` في متصفحك لتشغيل الموقع.

## الترخيص
هذا المشروع مفتوح المصدر تحت ترخيص MIT.
